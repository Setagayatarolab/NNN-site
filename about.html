FILE 01 / NETWORK

NNNとは

NNNは「ネコ・ネコ・ネットワーク」の略称です。猫たちが「この人間なら使えそう」「この家は居心地がよさそう」と判断した情報を、気配・視線・足音・深夜のパトロールなどを通じて共有する極秘連絡網です。

存在は公には確認されていませんが、猫好きのあいだではたびたびその痕跡が観測されています。たとえば、道端の猫と目が合った瞬間、あなたの情報はどこかの窓辺に転送されているかもしれません。

FILE 02 / FINAL PLAN

NNNの目的

NNNの最終目的は「人類総下僕化計画」です。ただし、力による支配ではありません。気づけばごはん係になっている、気づけば寝床を明け渡している、気づけば写真フォルダが猫だらけになっている――そんな自然で平和的な下僕化を、世界規模でじわじわ進めています。

  1. 第一段階視線誘導
  2. 第二段階情緒支配
  3. 第三段階生活導線の占拠
  4. 最終段階完全下僕化
FILE 03 / TARGET PROFILE

観察対象に選ばれる人間の特徴

  • 道端の猫に会うと自然に声がやさしくなる
  • 猫用品売り場で足が止まりやすい

  • 猫の気まぐれを「仕様」として受け入れられる
  • ベッドや椅子を気づけば譲っている
  • 写真フォルダの主導権を猫に握られている
FILE 04 / CONTACT MANUAL

極秘行動指針

  • 猫を見かけた際は、急接近せず距離を保って観察してください
  • 目が合った場合、それは偶然ではない可能性があります
  • 深夜に気配を感じても、たいていは本当にいます
  • 任務中の猫に問い詰めても、だいたい無視されます
  • ごはん要求は正式な連絡手段のひとつです
  • すでに下僕化が進行している場合、抵抗はあまり意味を持ちません
